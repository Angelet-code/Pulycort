# Analisis y entregables

Esta carpeta separa entregables utiles de salidas brutas de procesamiento.

- `informes/`: documentos elaborados, informes ejecutivos, PDFs, HTML y previews.
- `outputs/`: transcripciones, capturas, logs, metadatos y resultados generados por herramientas.

Los outputs no son fuente de verdad por si solos. Deben citar video, audio, documento o reunion de procedencia.
