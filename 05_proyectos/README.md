# Proyectos

Aqui van iniciativas concretas que pueden convertirse en apps, integraciones, automatizaciones o productos internos.

Cada proyecto deberia tener:

- `README.md` con objetivo, alcance, fuentes y estado.
- Carpeta de contexto y requisitos.
- Carpeta de arquitectura o decisiones tecnicas.
- Carpeta de prototipos o app cuando exista codigo.

Proyecto activo inicial:

- `pulycort_odoo_maquinas/`: integracion entre software de maquinas de produccion y Odoo.
